# Rome Doc Viewer - User Guide

[](#annotation-marker-a5308326-0606-4c76-b8c5-0e97ace9ba51)
## Getting Started

**Initial Setup**
- Launch the app, click "Select Documentation Folder" to choose your markdown documentation directory
- The file tree will load automatically in the left sidebar

## Navigation

**File Tree**
- Click folders to expand/collapse them
- Click any `.md` file to view its content
- `.mermaid` files are also supported for diagrams

**Header Controls**
- **Folder icon** - Change documentation folder
- **Refresh icon** - Reload file tree
- **Text format icon** - Customize markdown styling (font sizes, code style, etc.)
- **Paintbrush icon** - Switch themes (Seez, Light, Dark)

## Working with Annotations

**Adding Annotations**
1. **Method 1**: Select text in the document → Right-click → "Add Annotation"
2. **Method 2**: Click the floating "+" button (bottom right)
3. Fill in:
   - **Anchor Text** - Text snippet to attach note to (pre-filled if you selected text)
   - **Note** - Your annotation content
   - **Color** - Visual highlight (yellow, red, blue, green, orange, purple)
   - **Tags** - Optional categorization
4. Click "Add"

**Viewing Annotations**
- **Left Gutter** - Colored bookmark icons show annotation locations
- **Badge Counter** - Top right shows total annotations
- Click any gutter icon to view annotation details
- Click the badge counter to see all annotations

**Managing Annotations**
- **Edit**: Click gutter icon → "Edit" button
- **Delete**: Click gutter icon → "Delete" button
- **Collapse Gutter**: Click the chevron at top of gutter to hide/show annotations

## Features

**Markdown Rendering**
- Full markdown support with syntax highlighting
- Mermaid diagram rendering
- Clickable links
- Tables, code blocks, blockquotes

**Annotations Storage**
- Annotations are stored directly in markdown files
- A special section at the end of each file
- Portable - annotations travel with your documentation

**Search** (if enabled in file tree)
- Search for files across your documentation

## Tips

- Annotations automatically calculate line numbers based on anchor text
- Use tags to organize annotations by topic
- Different colors help categorize types of notes (questions=red, important=orange, etc.)
- Collapse the annotation gutter for distraction-free reading
